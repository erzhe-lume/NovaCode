## NovaCode 架构图 + 执行流程图生成（archify 技能）

用 archify 技能为 NovaCode 项目生成了两张独立交互式 HTML 图：

### 1. 架构图（architecture）`docs/novacode-architecture.html`
- **类型**: architecture (schema v1, showcase)
- **内容**: 5 层架构（交互/引擎/工具/记忆/安全）+ 14 个组件 + 5 个区域边界 + 7 条关键连接
- **布局**: viewBox 1100×540，agent 居中，permission 正下方对齐避免边界贴线
- **验证**: ok=true，0 errors / 0 warnings，visual-check ok=true
- **JSON 源**: `docs/novacode-architecture.json`

### 2. 执行流程图（workflow）`docs/novacode-workflow.html`
- **类型**: workflow (schema v2, showcase)
- **内容**: ReAct Agent Loop — 4 泳道 × 10 节点 × 10 条边
  - 主链路: 用户输入 → 斜杠检查 → Agent.run() → 迭代开始 → LLM流式 → 有工具? → 五层权限 → 工具执行
  - 循环回注: 工具执行 → 迭代开始（return edge, auto route）
  - 停止分支: 迭代上限 → 停止条件（drop route）
  - 自然结束: 有工具? → 自然结束（branch edge）
- **布局**: viewBox 1150×660，3 阶段 + 2 组（ReAct循环 / 安全收敛）
- **验证**: ok=true，0 errors / 0 warnings，visual-check 环境受限未通过（deliver 已验证）
- **JSON 源**: `docs/novacode-workflow.json`

### archify 使用要点（踩坑记录）
- **不要手动设 fromSide/toSide/via 直到诊断要求**——首版全手动设导致大量 endpoint-side-direction + edge-through-node 错误
- 跨层竖向连接需要显式 `fromSide: "bottom", toSide: "top"`（诊断要求时才加）
- 标签互叠时用 `labelDy` 微调，多个 bottom 出口的标签要错开足够距离
- workflow schema v2 有最小 viewBox 限制（动态计算），节点加宽后最小 viewBox 会增大
- sublabel 文字过长会导致 desktop-readability 失败（1440px 视口投影字号 < 6px）
