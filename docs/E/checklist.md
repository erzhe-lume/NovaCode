# 上下文管理 Checklist（第 8 章）

> 每一项通过运行代码或观察行为来验证，聚焦系统行为。

## 实现完整性
- [ ] TokenEstimator 已实现（验证：`mvn -q compile` 通过，一次性 main 输出锚定估算结果）
- [ ] Summarizer 已实现，`extractSummary` 能丢弃草稿（验证：假文本 `<draft>…</draft><summary>…</summary>` 提取出 summary 段）
- [ ] ContextManager 已实现，`spillOversized` 能写文件并替换历史（验证：一次性 main 断言存盘文件存在、历史变短）
- [ ] 单条工具结果超阈值 → 存盘 + 预览（AC1）（验证：构造 > 2000 token 工具结果，观察文件与历史）
- [ ] 单条消息工具结果合计超阈值 → 从大到小存盘（AC2）（验证：构造多个不同大小工具结果，观察存盘的是最大的）
- [ ] 逼近窗口 → 生成结构化摘要、保留近期、出现边界消息（AC3）（验证：长历史触发压缩，观察历史结构）
- [ ] 压缩前后 USER 原始消息逐字节一致（AC4）（验证：对比压缩前后历史里的 USER content）
- [ ] 手动 `/compact` 触发压缩并反馈（AC5）（验证：输入 /compact 观察反馈与历史变化）
- [ ] 摘要连续失败 3 次熔断（AC6）（验证：3 次失败后自动不再尝试）
- [ ] 摘要含五固定部分且草稿不残留（AC7）（验证：检查摘要消息内容）
