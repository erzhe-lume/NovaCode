# 命令注册与分发机制 Spec

## 背景

当前终端 Agent 的输入处理把所有斜杠命令硬编码在界面模型的提交逻辑里（`/exit`、`/plan`、`/do`、`/compact`、`/new`、`/sessions`），每条命令用一串 `if` 判断，命令实现和界面渲染耦合在一起。新增一条命令要改核心入口；清屏、查状态、列会话这类非对话操作也必须经过同一入口，无法复用、无法补全，也不利于后续 Skill 系统扩展。

本步引入一套统一的命令注册与分发机制：启动时集中登记内置命令（含元数据与别名冲突检测）；用户在回车的入口经过分流器——斜杠开头走本地命令分发、否则交给 Agent；命令实现不绑定渲染框架，通过一层界面控制接口操作界面。这样常用操作响应快、省 Token、行为确定，不用让 LLM 去处理清屏、查状态这类非对话杂事。

## 目标

- 命令元数据（名称、别名、描述、用法、类型、参数提示、处理函数）集中注册，启动期检测别名冲突并退出。
- 解析器识别斜杠前缀、命令名（转小写）与参数；空输入早返回；未命中引导 `/help`。
- 命令按执行模式分三类：纯本地、影响界面状态、送预设提示词给 AI。
- 界面控制接口隔离命令实现与渲染框架；状态栏联动模式标记。
- 回车入口分流器：命令走本地分发、非命令送 AI。
- 别名解析与 Tab 补全；隐藏命令不参与补全与帮助列表。
- 内置十个高频命令。

## 功能需求

- **F1 命令注册中心**：集中登记每条命令的元数据——名称、别名、简短描述、用法示例、命令类型、可选参数提示、是否隐藏、处理函数。启动阶段注册全部内置命令，检测名称或别名冲突（大小写不敏感），冲突时立即报错退出进程。

- **F2 命令解析**：识别输入是否以斜杠开头；以第一个空格为界，前面是命令名（转小写，大小写不敏感），后面是参数；纯空白输入在分流前即返回不处理；解析出的命令名在注册中心未命中时，显示 `/help` 引导。

- **F3 执行模式分类**：每条命令声明自己的执行模式——纯本地（只计算并展示，不改状态、不调 AI）、影响界面状态（改变消息区 / 模式 / 会话等界面状态）、预设提示词（把一段预设文本作为用户消息送进对话并启动 Agent）。

- **F4 界面控制接口**：抽出一个界面控制接口，命令实现只依赖它，不绑定具体渲染框架。接口至少支持：显示消息、发送用户消息给 Agent、切换权限模式、查询 Token 用量、刷新状态栏。状态栏上的权限模式标记（`[default]` / `[plan]` 等）与当前模式联动。

- **F5 回车分流器**：在用户提交输入的入口加分流——以斜杠开头走本地命令分发，其余作为普通消息送 Agent。命令分发本身不触发 Agent 对话（预设提示词类除外，由该类命令显式触发）。

- **F6 别名与补全**：命令支持别名，别名与主名等价触发同一处理函数；Tab 补全命令名——唯一匹配直接补全，多个候选显示候选列表，隐藏命令不出现在补全候选中。

- **F7 内置命令**：提供十个高频命令 `/help`、`/compact`、`/clear`、`/plan`、`/do`、`/session`、`/memory`、`/permission`、`/status`、`/review`。模式切换拆成两个动词——`/plan` 进入计划模式、`/do` 退回执行模式。此外保留既有的 `/new` 与 `/exit`（进程生命周期），统一迁入注册中心。

## 非功能需求

- **N1 常用命令响应快、省 Token**：纯本地与界面状态类命令不经过 Agent 对话循环（不进入流式会话、不消耗对话上下文），仅在本地完成并立即展示；`/compact` 是例外——它主动触发一次摘要压缩，属于界面状态类命令里唯一调用 LLM 的（第 8 章遗留行为）。

- **N2 行为确定**：同一条命令无论上下文如何，其结果可预期（清屏就是清屏、查状态就是查状态），不依赖模型判断。

- **N3 启动期冲突即退出**：别名冲突在进程启动阶段抛出致命错误并退出，不延迟到运行时。

- **N4 命令实现与渲染解耦**：命令处理函数只依赖界面控制接口，接口可在不同渲染框架下替换实现。

## 不做的事

- 用户自定义命令（注册用户自己的命令）——留给后续 Skill 系统。
- 动态生成提示词（命令的提示词内容在代码里写死，不在运行时拼接模型生成）。
- 命令级权限控制（哪个用户 / 场景能执行哪个命令）——留给后续。

## 验收标准

- **AC1**：启动时若内置命令存在名称或别名冲突，进程立即以非零退出码报错退出。
- **AC2**：输入 `/HELP` 或 `/Help`（大小写混合）等价于 `/help`。
- **AC3**：输入不存在的 `/foo` 时，显示帮助引导（提示用 `/help` 查看命令）。
- **AC4**：纯本地命令（如 `/help`、`/status`）执行时无任何 LLM 请求（无 Token 消耗、不进入流式会话）。
- **AC5**：`/plan` 后状态栏显示 `plan` 标记，`/do` 后回到 `default` 标记。
- **AC6**：Tab 补全——输入 `/pl` 按 Tab 唯一补全为 `/plan`；输入 `/s` 按 Tab 显示多个候选（如 `/session`、`/status`）。
- **AC7**：普通消息（不以斜杠开头）仍正常送 Agent 并流式回复。
- **AC8**：`/help` 列出全部非隐藏命令及其描述与用法。
- **AC9**：预设提示词类命令（`/review`、`/do`）把预设文本作为用户消息注入并启动 Agent。
- **AC10**：隐藏命令不出现在 `/help` 列表和 Tab 补全候选中。
