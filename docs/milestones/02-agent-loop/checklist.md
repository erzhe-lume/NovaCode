# Agent Loop Checklist

> 每一项通过运行代码或观察行为来验证，聚焦系统行为。

## 实现完整性
- [ ] 多轮自动连环：给「读 A 文件 → 据内容新建 B 文件」任务，Agent 自动多轮执行，无需用户中途催（验证：启动后发送该任务，观察 read_file → write_file 跨多轮自动出现）
- [ ] 自然完成：模型给出无工具调用纯文本时循环停止（验证：发送纯问答消息，一轮就结束）
- [ ] 迭代上限兜底：达到 50 轮即停并提示（验证：理论上 50 轮足够触发）
- [ ] 连续未知工具停止：达 3 轮阈值即停（验证：如触发则提示连续未知工具）
- [ ] 流出错恢复：provider 出错时提示、不退出、可继续对话（验证：临时改坏 base_url 测试）
- [ ] 事件流完备：UI 仅靠 AgentEvent 渲染（验证：StreamText / ToolUse / ToolResult / Usage / TurnComplete / LoopComplete 均被消费）
- [ ] 流式收集双路：文本实时显示同时完整工具调用被收集（验证：工具调用参数完整可解析）
- [ ] 保序分批并发：连续 READ 并发、有副作用串行，结果按原序回灌（验证：一次回复含多个 READ 工具时观察是否并发）
- [ ] 历史一致：取消/出错后历史仍配对合法（验证：中断后再发消息不报错）
- [ ] 用户取消：Esc/Ctrl+C 中断本轮不退出，空闲态 Ctrl+C 退出（验证：各按一次观察行为）
- [ ] 用量展示：状态栏显示累计 token（验证：多轮后观察数值增长）
- [ ] 进度展示：动态区显示当前迭代轮次（验证：多轮任务观察"第 N 轮"递增）
- [ ] Plan Mode：`/plan` 只给只读工具，`/do` 切回全工具执行（验证：/plan 后只能读文件，/do 后可写）

## 编译与测试
- [ ] `mvn compile` 无错误
- [ ] `mvn clean package -DskipTests` 打包成功
- [ ] 密钥不回显：对话区与任何输出均不出现 api_key

## 端到端场景
- [ ] 场景 1（多轮连环）：「读 pom.xml，在 src/main/resources 下新建一个 info.txt 写一句话摘要」→ 自动多轮 → 最终答复
- [ ] 场景 2（用户取消）：多步任务中途按 Ctrl+C → 回空闲态 → 再发一条正常对话
- [ ] 场景 3（Plan Mode）：`/plan` → 「帮我设计一个新功能的方案」→ 只出现读工具 → `/do` → 切回全工具
